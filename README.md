# Web Browser UI Clone

A front-end web browser interface inspired by the Google Chrome user interface, developed using HTML5 and CSS3.

The project recreates different browser screens and user flows, including Chrome profile selection, sign-in, guest mode, profile setup, and a Google-style browser homepage.

## 🚀 Features

- Chrome-inspired profile selection interface
- Add new browser profile interface
- Chrome sign-in page
- Guest browsing interface
- Profile setup page
- Google-style homepage
- Search bar UI
- Website shortcut section
- Responsive front-end layouts
- Multiple interconnected HTML pages
- Custom CSS styling

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design
